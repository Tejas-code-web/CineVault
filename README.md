# CineVault

CineVault is a responsive movie search web application built using HTML, CSS, and JavaScript. It uses the OMDb API to search for movies and display detailed movie information.

## Features

- Search for movies using the OMDb API
- Display multiple movie search results
- Show movie posters, titles, years, and IMDb ratings
- View detailed movie information
- Open movies directly on IMDb
- Add and remove movies from Favorites
- Store Favorites using Local Storage
- Search movies using the Enter key
- Responsive design for desktop, tablet, and mobile devices
- Handles invalid searches and API/network errors

## Technologies Used

- HTML5
- CSS3
- JavaScript
- OMDb API
- Local Storage

## How It Works

- Enter the movie name in the search bar
- Send a request to the OMDb API
- Display the matching movie search results
- Select a movie to view detailed information
- Add or remove movies from Favorite
- Store Favorites using Local Storage
- Open the selected movie directly on IMDb
- Handle invalid searches and API/network errors

## Project Structure

- `index.html` - Main structure of the CineVault application
- `style.css` - Styling and responsive design
- `script.js` - Movie search, API requests, movie details, and Favorites functionality
- `README.md` - Project documentation
